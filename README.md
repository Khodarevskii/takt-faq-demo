# Такт — вопросы

Адаптивная демонстрационная страница на **React 19 + TypeScript + Vite**, реализованная по четырём версиям Figma: 360, 768, 1280 и 1920 px. Обычный CSS, без UI-фреймворка и абсолютного позиционирования контента.

- [Открыть демо](https://khodarevskii.github.io/takt-faq-demo/)
- [Исходный макет](https://www.figma.com/design/LzW35BTadJwWMW4kF1jSF8/?node-id=3-47)

## Запуск

Нужны Node.js 22 LTS или новее и npm.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

`build` сначала проверяет TypeScript, затем создаёт production-сборку в `dist/`. Для просмотра нужен HTTP-сервер: открытие `index.html` через `file://` не поддерживается ES-модулями браузера.

## Структура

```text
src/
  App.tsx                    # Поиск, фильтрация, навигация по темам
  components/
    AccordionItem.tsx        # Доступный аккордеон
    SiteChrome.tsx           # Шапка, мобильное меню, подвал
    Modal.tsx                # Диалог с нативной блокировкой фокуса
  data/faq.ts                # Типизированные вопросы и редакционные тексты
  styles.css                 # Токены, адаптивная сетка, состояния
public/assets/               # Оригинальные ресурсы Figma
dist/                        # Готовая сборка
```

## Поведение

- Поиск по вопросам и ответам, без учёта регистра и различия «е/ё»; несколько слов объединяются условием AND.
- Независимое раскрытие вопросов; первый ответ открыт при загрузке.
- Якорная навигация с подсветкой текущей темы, закреплённое меню на десктопе.
- Мобильное меню, закрытие по Escape; семантические кнопки, aria-expanded, видимый фокус, ссылка пропуска навигации.
- Уважение `prefers-reduced-motion`.
- Все шрифты и изображения локальные: внешних запросов к Figma или Google Fonts при работе нет.

## Границы демоверсии

В макете показан только первый раскрытый ответ. Остальные тексты — редакционные черновики, отмеченные `draft: true` и подписью при раскрытии. Особенно важно утвердить цены, обработку данных и правила сеансов перед реальным запуском.

Почта и телефон оставлены как в макете: `[ПОЧТА ЦЕНТРА]` и `[ТЕЛЕФОН ЦЕНТРА]`. Авторизация, оплата, дневник и юридические документы не подключены. Пункты вне реализованной страницы открывают честное уведомление о демоверсии. Кнопки срочной помощи используют `tel:112`, как указано в дизайне.

На узких экранах шапка немного уплотнена, чтобы кнопка меню не выходила за край, как в исходном макете 360 px. Высоты блоков зависят от текста, а не фиксированы.

## Публикация на GitHub Pages

Ветка `main` содержит исходники и `dist`, ветка `gh-pages` — только готовую сборку. Pages публикуется из корня `gh-pages`.

Обновление после правок:

```sh
npm ci
npm run build
git add .
git commit -m "Update FAQ page"
git push origin main
git subtree push --prefix dist origin gh-pages
```

## Проверка

Проверены production-сборка, поиск с результатом и без результата, раскрытие ответов, мобильное меню и клавиатурное управление. Макет проверялся в Chromium; отдельная проверка на физических iOS/Android-устройствах и в Safari не проводилась.

Графика взята из предоставленного пользователем макета. Права на дизайн остаются у его правообладателя. Шрифты Fontsource распространяются по собственным открытым лицензиям; они включены в `public/licenses/`.
